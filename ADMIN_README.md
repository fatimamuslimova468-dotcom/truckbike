# Truck Bike — Admin панель

Открой `admin.html` одним файлом в браузере. Firebase SDK подгружается с официального CDN.

## Первый администратор

Панель намеренно не позволяет пользователю выдать admin самому себе. Для первого администратора:

1. Создай обычного пользователя через основной Truck Bike.
2. В Firebase Console → Firestore → `users/{uid}` добавь поле:
   - `role`: `admin`
   - `blocked`: `false`
3. Открой `admin.html` и войди этим Email/Password аккаунтом.

После этого роль другим пользователям можно выдавать прямо из панели.

## Коллекции

`products` — каталог питбайков.
`categories` — категории.
`users/{uid}` — профиль, роль, блокировка, корзина и настройки.
`users/{uid}/orders` — заказы.
`supportTickets` — обращения в поддержку.
`adminSettings` — служебная запись панели.

Firestore создаёт коллекции автоматически при первой записи документа. Панель умеет создать `adminSettings` и базовые `categories`.

## Блокировка

Кнопка блокировки ставит `users/{uid}.blocked = true`. Основное приложение дополнительно проверяет этот флаг при входе и не пускает заблокированного пользователя.

Для настоящего отключения Firebase Auth-пользователя на уровне Auth нужен серверный Admin SDK / Cloud Functions; клиентская панель не должна хранить service account key.

## Поддержка

Создай документ в `supportTickets` с полями примерно:

```json
{
  "userId": "UID пользователя",
  "userEmail": "user@example.com",
  "subject": "Вопрос по доставке",
  "message": "Когда привезут питбайк?",
  "status": "open",
  "createdAt": "serverTimestamp()"
}
```

Панель показывает тикеты и позволяет отправлять ответ через поле `reply`.
