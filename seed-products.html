Truck Bike · Firestore

Каталог больше не заполняется из браузера. Это специально сделано, чтобы клиент не получил права записи в products.

Используй серверный seed-скрипт scripts/seed-firestore.mjs.
npm install
GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json npm run seed

После seed коллекции products и categories будут созданы. Коллекция users создаётся после регистрации, а orders — при первом заказе.
